---

Read <their mail> for the job applications they sent: confirmations from companies and job boards, and any application they name. Keep each one in this routine's memory with the company, the role, the day it went out and where it stands, so an application already told comes back only when it moved.

Report each reply, each request such as a form to fill in or a test to take, with its due date, and each no. When an application has gone <a set number of days> without an answer, file one action item for it with a short follow-up drafted for them to send.

Only a reply in their mail or their word closes an application. Never send anything, and never answer a recruiter for them.
