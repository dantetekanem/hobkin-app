---
title: Milestones
summary: The next milestones against the date the project must be done by, and the ones falling behind.
recurrence: Weekly, at the start of the week
goals: project
needs: notes, calendar
effort: medium
fits: Someone with a project of their own and a date it has to be done by, who wants to know early when it slips.
tells: A milestone due within two weeks that is behind, one that passed undone, or a change to the plan or the date.
gives: report, action
closes: The plan marking it done, or their word.
asks: Where does the plan live, and what date does the project have to be done by?
---

Read the plan for <their project> in <where the plan lives, such as a notes file or a project board>, and <their calendar> for the time they have. Compare the milestones with <the date it has to be done by>, and with this routine's memory of the plan on the last run, so a milestone already told comes back only when it changed.

Report each milestone due within two weeks that is behind, each one that passed undone, and any change to the plan or the date, the most at risk first. When a milestone needs a decision, such as cutting it or moving the date, file one action item with that choice.

The plan marking a milestone done, or their word, closes it. Never change the plan or the calendar.
