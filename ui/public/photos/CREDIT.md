# Milky Way photograph

`milky-way.jpg` is ESO's 1920 × 1200 wallpaper rendition of **The Milky Way panorama**, image eso0932a, released 14 September 2009.

Credit (unaltered): **ESO/S. Brunier**.

- Source: https://www.eso.org/public/images/eso0932a/
- Exact download: https://cdn.eso.org/images/wallpaper4/eso0932a.jpg
- Usage policy, verified 13 November 2026: https://www.eso.org/public/copyright/
- License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/

ESO permits reuse and adaptation with clear, visible full credit, without suggesting endorsement. The image page identifies this as photographic, not AI generated. The restriction on the unavailable full 800-million-pixel original does not describe this publicly offered wallpaper rendition.

Stored bytes are unchanged from the wallpaper download: JPEG, 981827 bytes, 1920 × 1200 pixels; SHA-256 `6df7ce3cea79841c15e7d04750c073b6680671efa01be3da5eae433846e28c70`. The app crops responsively with `cover` and darkens it with a palette-colored overlay. Visible in-app credit identifies those presentation changes and links to source and license. No generated content or private photographs are used.

This application-owned, fixed asset is bundled locally; rendering never requests ESO or another external image server. The host accepts only the literal `milky-way` ID or null through `appearance.photo`, never image URLs, paths or bytes. Other photo uploads/imports and a theme gallery are not implemented.
