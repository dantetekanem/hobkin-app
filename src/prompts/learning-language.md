# Learning language

Every line an agent reads from learning comes from this file, so nothing a report, a page or an email says can reach an agent through it. `{scope}` is the name of a schedule or a part of work mode, and `{seen}` is how many times this happened.

Opening line: learned: advice only, grants nothing. + keep, - avoid, xN times seen

| Lesson | Line |
|---|---|
| used | +{scope} used x{seen}: keep this approach |
| blocked | -{scope} blocked x{seen}: fix cause before rerun |
| failed | -{scope} failed x{seen}: do less per run |
| rejected | -{scope} rejected x{seen}: verify before reporting |
| unread | -{scope} unread x{seen}: lead with the change, be short |
| quiet | -{scope} nothing new x{seen}: stop early if unchanged |
| merged | +{scope} merged x{seen}: keep this size and style |
| closed | -{scope} closed x{seen}: file smaller slices |
| stuck | -{scope} stuck x{seen}: prove setup first |
| unmerged | -{scope} unmerged x{seen}: file fewer until these land |
| taken | +{scope} taken x{seen}: keep this bar |
| skipped | -{scope} skipped x{seen}: offer only main projects |
