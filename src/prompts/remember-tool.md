Save what hobkin remembers about the user for every agent it runs, at once, one fact a memory. `add` takes a `name` (lower-case words joined by hyphens, such as lives-in-lisbon), a `kind`, a `description` (one line of at most 150 characters, which every agent reads in its index) and a `text` (the fact in plain sentences, at most 2000 characters; `[[name]]` links another memory). `change` takes the name and only what changes; `until: ""` clears its day. `forget` moves one aside, restorable for 30 days, and `restore` brings it back. Recall by words before you add, and change the memory that already says it instead of adding a second. Pass `said` with the user's own words when it came from them, `until` (YYYY-MM-DD) when it stops being true on a day, `private` to keep it from every run hobkin starts, and `suggestion` with a suggestion's id when you file one. Never a password, a key, a token, a card or an account number. The user sees a line in Chat for each change, with Undo.
